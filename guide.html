사용법

처음이어도 1분이면 충분합니다.

1. 이렇게 씁니다

  1. 노트를 텍스트로 준비합니다

    PPT라면 슬라이드 내용을 복사하고, 손필기라면 핵심만 옮겨 적으세요. 이미지나 PDF 업로드는 아직 지원하지 않습니다.

  2. 한 번에 한 주제씩 넣습니다

    8주치를 한꺼번에 넣으면 문제가 얕아집니다. 챕터 하나 또는 강의 한 회차 분량이 가장 좋습니다.

  3. 답을 가린 채 먼저 풀어봅니다

    정답은 접혀 있습니다. 5초라도 스스로 떠올려 본 뒤에 펼치는 것이 기억에 훨씬 오래 남습니다.

  4. 틀린 문제의 '노트 근거'를 찾아 읽습니다

    각 문제에는 노트 어느 부분에서 나왔는지가 함께 표시됩니다. 그 부분만 다시 읽으면 복습이 끝납니다.

2. 좋은 문제가 나오는 노트

✓ 이런 노트가 좋습니다

  • 개념의 정의가 문장으로 적혀 있다
  • A와 B를 비교한 내용이 있다
  • 장단점, 예시, 조건이 함께 적혀 있다
  • 용어와 설명이 짝지어져 있다

✕ 이런 노트는 아쉽습니다

  • 단어만 나열된 목차
  • 수식이나 그림 위주라 텍스트가 거의 없다
  • "중요!!" 같은 표시만 있고 내용이 없다
  • 여러 과목이 섞여 있다

3. 이런 메시지가 뜬다면

메시지원인이렇게 해보세요
강의노트를 먼저 붙여넣어 주세요 입력창이 비어 있음 노트를 붙여넣거나 예시 노트 넣기를 눌러 체험해 보세요
내용이 너무 짧아요 30자 미만 개념 설명이 담긴 문단을 조금 더 넣어 주세요
노트가 너무 깁니다 8,000자 초과 챕터 단위로 나눠서 두세 번에 걸쳐 만들어 주세요
요청이 몰리고 있어요 API 호출 한도 초과 (429) 30초 정도 기다렸다가 다시 시도해 주세요
AI 서버가 응답하지 않습니다 AI 서비스 장애 (5xx) 잠시 후 다시 시도해 주세요. 입력한 노트는 지워지지 않습니다
응답이 너무 늦어졌습니다 처리 지연 / 타임아웃 노트를 줄이거나 문제 수를 10개 → 5개로 낮춰 보세요
서버에 연결하지 못했습니다 네트워크 끊김 인터넷 연결을 확인한 뒤 다시 시도해 주세요

4. 자주 묻는 질문

제가 넣은 노트가 어딘가에 저장되나요?

아니요. 퀴즈노트에는 데이터베이스가 없고, 서버 로그에도 노트 본문을 남기지 않습니다. 다만 문제를 만드는 과정에서 노트가 OpenAI 서버로 전송되므로, 개인정보나 회사·학교의 기밀 자료는 넣지 마세요.

영어 노트도 되나요?

됩니다. 노트에 쓰인 언어를 그대로 따라가서, 영어 노트에는 영어 문제가 나옵니다. 한국어 문제로 받고 싶다면 노트 맨 위에 "한국어로 출제" 같은 문장을 한 줄 적어 두세요.

문제가 노트에 없는 내용으로 나왔어요.

AI는 확률적으로 답을 만들기 때문에 드물게 노트 밖으로 나갈 수 있습니다. 그래서 각 문제에 노트 근거를 함께 표시합니다. 근거가 노트와 맞지 않는 문제는 그냥 넘기시면 됩니다. 노트가 짧을수록 이런 일이 잦아지니, 설명이 충분한 부분을 넣어 주세요.

같은 노트로 다시 만들면 같은 문제가 나오나요?

아닙니다. 매번 조금씩 다른 문제가 나옵니다. 시험 전날 같은 범위를 두 번 돌려서 새 문제로 다시 확인해 보는 것도 좋은 방법입니다.

만든 문제를 저장할 수 있나요?

결과 위쪽의 전체 복사 버튼으로 마크다운 텍스트를 클립보드에 담거나, txt 저장으로 파일을 내려받을 수 있습니다. 브라우저 인쇄 기능을 쓰면 정답이 펼쳐진 상태로 PDF 저장도 됩니다.

무료인가요?

학습용으로 만든 개인 프로젝트라 이용료는 없습니다. 다만 AI 호출에는 실제 비용이 들기 때문에, 짧은 시간에 너무 많이 호출하면 일시적으로 제한 메시지가 뜰 수 있습니다.
