## 2. AI 코딩 도구 사용 과정

사용 도구: **Claude (Cowork)**

### 진행 순서

| 단계 | 내가 요청한 것 | AI가 한 것 | 내가 판단·결정한 것 |
|---|---|---|---|
| 1 | 과제 요구사항 전문 전달 | 아이디어 3개 제안 | "대학생이 실제로 쓸 만한 주제"로 다시 요청 |
| 2 | 실사용 가능한 주제 재요청 | 강의노트→퀴즈 / 자소서 첨삭 / 중고거래 글 3개 제안 | **강의노트 → 퀴즈 생성기** 선택 |
| 3 | 사용할 AI API 결정 | Claude / OpenAI / Gemini 비교 제시 | **OpenAI** 선택 |
| 4 | 보너스 과제 선택 | 다크 모드 / 마이크로 인터랙션 제시 | **다크 모드** 선택 |
| 5 | 기획서 작성 | 목적·타겟·페이지 구성·실패 처리 기준 정리 | 실패 처리를 3종 모두 넣기로 결정 |
| 6 | 프론트엔드 구현 | HTML 4페이지 + CSS + JS 작성 | 페이지 4개 구성, 정답 가리기 UX 채택 |
| 7 | 백엔드 구현 | `api/quiz.py` 서버리스 함수 작성 | 프롬프트에 "노트 밖 출제 금지" 규칙 추가 요구 |
| 8 | 검증 | 백엔드 28개 테스트, 스크린샷 자동 촬영 | 스티키 헤더 겹침 문제 발견 → 수정 |
| 9 | 문서화 | README, 기획서, 증빙 자료 정리 | 배포 URL 자리 확인 |

### AI가 만든 코드에서 직접 잡은 문제

| # | 발견한 문제 | 원인 | 수정 방법 |
|---|---|---|---|
| 1 | 결과가 생성된 뒤 스크롤 이동하면 결과 제목이 상단 고정 헤더에 가려짐 | `position: sticky` 헤더 높이만큼 겹침 | `#result-area` 에 `scroll-margin-top: calc(var(--header-h) + 20px)` 추가 |
| 2 | AI가 OX 문제에 보기를 3개(`참/거짓/몰라`) 반환하는 경우가 있음 | 모델이 형식 지시를 항상 지키지는 않음 | 백엔드 `normalize()` 에서 OX는 `["O","X"]` 로 강제하고 정답도 O/X로 변환 |
| 3 | 질문이나 정답이 빈 문항이 섞여 들어옴 | 모델 출력 품질 편차 | `normalize()` 에서 빈 문항을 제거하고 번호를 다시 부여 |
| 4 | 시크릿 모드에서 `localStorage` 접근이 예외를 던짐 | 브라우저가 스토리지 접근을 차단 | 읽기·쓰기를 모두 `try/catch` 로 감쌈 |

### 오류를 파악한 방법

1. **재현** — 어떤 입력에서 문제가 생기는지 좁힌다 (예: OX 유형만 선택했을 때)
2. **경계 확인** — 프론트 문제인지 백엔드 문제인지 나눈다.
   개발자 도구 Network 탭에서 `/api/quiz` 의 **응답 JSON**을 보고,
   응답이 이미 이상하면 백엔드, 응답은 정상인데 화면이 이상하면 프론트로 판단한다.
3. **수정 위치 결정** — 모델 출력은 통제할 수 없으므로,
   "프롬프트로 요청하되 코드로 방어한다"는 원칙을 세우고 백엔드 정규화 단계에서 막았다.
4. **검증** — 모의 응답으로 테스트를 다시 돌려 같은 오류가 재발하지 않는지 확인한다.

### 스크린샷

AI 코딩 도구와의 대화 화면 캡처는 제출 시 별도로 첨부합니다.
(위 표의 각 단계에 대응하는 대화 구간을 캡처하면 충분합니다.)

### 실제 연동에서 겪은 문제와 해결

| # | 증상 | 원인 | 해결 |
|---|---|---|---|
| 1 | `invalid_api_key` | 다른 서비스의 토큰을 OpenAI 본사 주소로 보냄 | `OPENAI_BASE_URL` 환경 변수로 API 서버 주소를 교체 가능하게 변경 |
| 2 | 400 `unsupported_feature` | GPT-5 계열은 `max_tokens`·`temperature` 를 받지 않음 | 파라미터 조합을 단계적으로 줄이며 재시도하는 구조 추가 |
| 3 | 25초 타임아웃 | 추론 모델의 응답이 25초를 넘김 | 백엔드 50초 / 프론트 55초 / Vercel 60초로 계층 정렬, 경과 시간 표시 추가 |
